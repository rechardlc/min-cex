# go-zero-demo

这是一个面向中小型企业后端场景的 `go-zero` 学习型目录骨架。

目标不是一次性做成完整项目，而是先把目录规则、分层职责、服务边界和学习顺序搭起来，方便你后续边学边填。

## 目录设计原则

1. `apps/` 按服务拆分，符合中小型企业逐步微服务化的常见路径。
2. `pkg/` 放可复用公共能力，避免把所有东西都塞进单个服务。
3. `deploy/` 放本地运行和部署相关内容，方便后续接入 Docker Compose。
4. 每个关键代码文件旁边配一个同名 `.md`，用于说明职责和学习重点。

## 建议学习顺序

1. 先看 `DIRECTORY_RULES.md`
2. 再看 `docs/LEARNING_PATH.md`
3. 从 `apps/gateway` 开始理解 go-zero API 服务
4. 再看 `apps/account-rpc` 理解 zrpc 服务
5. 最后看 `pkg/` 和 `deploy/`

## 当前骨架包含

- 一个 API 网关服务样例
- 一个 RPC 服务样例
- 一组公共包样例
- 一份进度记录文档
- 一份学习路线文档

## 你后续可以怎么用

- 每学完一个目录，就更新 `PROGRESS_TRACKER.md`
- 每补一个真实功能，就在对应文件的说明 `.md` 里追加理解
- 等你开始写业务时，再逐步补数据库、缓存、消息队列、鉴权、日志、监控等模块
